# MetaLab
A MacOS ExifTool GUI.
The final step before publishing your photographs: inspect metadata, edit essential details, preview your images, and save individually or in batches.
It is designed as a local desktop tool.

## Features
- Import individual images or folders
- 
- Read and edit EXIF metadata
- Batch-save metadata changes
- Save in place or save as copies
- Rename photos before saving
- Keep file extensions protected while renaming
- Edit GPS coordinates with map support
- Apply reusable camera, lens, digitization, and credit templates
- Small-thumbnail and no-thumbnail file navigation modes
- Local processing with bundled ExifTool
- Add color labels to photographs for quick organization, with optional Finder tag synchronization.
- Supports Chinese and English interface languages, switchable in Settings.

## Selected files are processed on your Mac.
MetaLab does not upload your photos, files, or EXIF metadata to any external device.
MetaLab does not include analytics, advertising tracking, or telemetry.
GPS and map-related features may use Apple system frameworks such as MapKit, CoreLocation, and geocoding services.
ExifTool is bundled and runs locally for metadata reading and writing.
